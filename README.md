# writing-manuals：把截圖與使用故事寫成一份交得出去的手冊

系統做完了，合約上還有一項「結案手冊」。內容其實不難寫，難的是 **Word 排版**：標題樣式套來套去還是不一致，自動目錄的頁碼一改就跑掉，圖說有人寫「圖一」有人寫「圖 1-1」，圖片被擠到下一頁，前一頁留下一大片空白；最後改了一個字，整本又重排一次。

這個 skill 讓 Claude 把你的截圖和使用故事寫成一份使用說明書，排好版，交給你 Word 與 PDF 兩個檔。你專心看內容對不對，排版的雜事交給它。

---

## 它能幫你做什麼

你只要給它一批系統的截圖，加上一段「使用者會怎麼操作」的說明，它就能還你一份可以直接交出去的使用說明書：Word 與 PDF 各一份。

這份手冊打開來像一份整齊的純文字檔，沒有 Word 的標題樣式、自動目錄或框線，所以收到的人自己改字也不容易弄亂。每張圖下方都是「圖 N.M. 名稱」，圖和圖說留在同一頁；目錄頁碼是讓 Word 實際排過一次量出來的，不是估的；空白太多的頁會補上說明文字，而不是放大圖片或塞空行。

內容也有人把關。寫完之後，Claude 會逐一檢查圖號有沒有跳號、用語前後是否一致，接著請一位「從沒用過這個系統的人」只看手冊試讀，哪裡看不懂、哪一步漏了，就回頭補。截圖重拍之後，內文提到的按鈕名稱與數字也會一起更新。章節多的時候，它會請幾位幫手平行各寫一兩章，自己負責把關與合併。

不用記任何指令，用平常的話說就好，例如「幫我寫結案手冊」「手冊目錄頁碼不對」「手冊有幾頁空白太多」。Claude 會把工作拆成一份 todo 清單，一項一項勾，你隨時看得到做到哪裡；規劃好章節與每張圖放哪裡之後，它會先給你確認再動筆。

---

## 材料從哪裡來

那麼，這些截圖和使用說明要從哪裡來？兩條路都可以，沒有哪一條是必要前提：

- **接著 [capturing-journeys](https://github.com/AcaiHi/capturing-journeys-skills) 往下做**：如果你已經用它把系統沿著使用故事拍過一遍，那些截圖、使用故事、每張圖的圖說與備註都可以直接當起點，章節順序也沿用故事。
- **完全自己給**：手邊已經有的截圖、寫到一半的文字稿，或甚至只是口頭描述「這個系統是做什麼的、使用者會怎麼操作」都行。缺什麼，Claude 會問你；需要時也會去讀程式碼，確認系統實際的行為，不憑印象寫。

---

## 一個例子：排班系統

假設你做了一個護理排班系統，手邊有八張截圖，再加上一句話：「內科病房護理長登入後，建立三月份班表，看過休假申請，按下『開始求解』，得到排好的班表。」你對 Claude 說「幫我寫結案手冊」，就這樣。

它先依這句話把截圖排成四章：「登入」「建立班表」「審核休假申請」「求解與檢視結果」，並列出每章放哪幾張圖、圖名叫什麼，給你看。你點頭之後，它才動筆，寫完交出一份十來頁的 Word 與 PDF。接著請一位沒用過這個系統的讀者試讀，他說：「建好班表之後，我不知道要去哪裡看休假申請。」原來中間漏了一步，Claude 補上一段，再附一張側邊欄的圖。過幾天，你把「開始求解」改名成「排班」並重拍了那張圖，只要再說一聲，內文裡每一處提到這顆按鈕的地方都會換成新名字，目錄頁碼也會重新量過，新的 Word 與 PDF 就好了。

## 偏好很好改

預設的排版與寫法，是過去幾個專案一路累積下來的習慣，不見得適合你。不合口味，就改。

排版比較單純。字級、縮排、對齊、行距、表格、圖框顏色這些，直接說「內文不要縮排」「表格內距加大一點」就好；想自己動手，也可以打開偏好檔改。

真正值得花心思的是寫作風格。如果你讀了覺得「這不像我會寫的東西」，別客氣，告訴它你要它照什麼寫，來源不拘。你可以貼上平常自己在用的那段 prompt，說「照這段要求寫」；也可以說「用 XXX skill 的寫法」，把你習慣的寫作規範交給它；或者丟一份以前交過的舊手冊，說「照這份的語氣和結構寫」。

不管你給的是哪一種，Claude 都會把這個來源記進你專案的寫作偏好，之後每一章、每次重排都照它來，不用每次重新交代。

排版只是外觀，寫作風格才決定這份手冊讀起來像誰寫的，所以後者最值得花點時間講清楚。

## 安裝

需要 Python 3（缺的套件 Claude 會提醒你裝）。要產生 PDF 與實測的目錄頁碼，需要 Windows 加上 Microsoft Word；沒有 Word 也能產生 Word 檔，只是目錄頁碼會是占位數字，也不會有 PDF。

1. 把這個資料夾放在 `~/.claude/skills/writing-manuals/`。
2. **開一個新的 session**，skill 才會載入。
3. 在專案裡跟 Claude 說「幫我寫使用手冊」就可以開始。

## 常見問題

**Q：一定要先用 capturing-journeys 拍圖嗎？**
不用。有它的成果會比較省事，但你自己的截圖、文字稿或口頭描述都可以當起點。

**Q：手冊交出去之後，別人改得動嗎？**
可以。因為沒有用 Word 的結構功能，打開就是一般段落，改字不會牽動整份版面；只是目錄頁碼要重新量，請 Claude 重排一次即可。

**Q：可以只改一章嗎？**
可以，直接說要改哪一章，改完它會重排、重新檢查頁碼與空白。

**Q：建置時說檔案無法覆寫？**
舊的 Word 或 PDF 還開著時，檔案無法覆寫。Claude 會提醒你關閉，不會強制關掉你的程式。
