# 章節 Markdown 語法

本文件說明 `build_manual.py` 實際認得的章節語法，以及 `check_manual.py` 會檢查的規則。只支援這裡列出的寫法；其他 Markdown 語法（粗體、清單、連結、程式碼區塊等）不會被轉換，會以原字元出現在內文中。

## 檔名與資料夾

- 章節檔放在設定檔 `chaptersDir`（預設 `docs/manual/chapters/`）。
- 檔名為「兩位數編號-名稱.md」，例如 `00-前言.md`、`01-前台瀏覽.md`、`11-附錄-欄位說明.md`。只有符合 `[0-9][0-9]-*.md` 的檔案會被讀取，依檔名排序組成全書。
- 編號從 00 起連續，不可缺號或重號（check：order）。
- 檔案編碼 UTF-8。

## 標題與編號

| 寫法 | 意義 | 輸出外觀 |
|---|---|---|
| `# 第 1 章 章名` | 章標題，每檔恰好一個 | 18 pt 粗體主色，下接一條灰色「─」分隔線；列入目錄 |
| `## 1.1 節名` | 節 | 「▍」標記 + 14 pt 粗體 |
| `### 1.1.1 小節名` | 小節 | 「■」標記 + 12 pt 粗體 |

- `#` 後面要有一個空格。
- 章標題若寫「第 N 章」，N 必須等於檔號（00 前言可不寫「第 0 章」）。
- 節編號：`##` 用 `N.M`，`###` 用 `N.M.K`；N 等於章號，M、K 從 1 起依序遞增，小節必須在對應的節之下（check：heading）。
- 不帶編號的 `##`、`###` 也可以（例如「本章重點」），不檢查編號。
- 章與章之間不換頁：章標題前自動插入一個空白段落，接續前文排版。目錄只列章標題（`#`）。

## 內文段落

- 每一個非空白行就是一個段落；空白行只作分隔，不會產生空段落。一段文字不要硬斷行。
- 段落一律首行縮排 2 字元、左右對齊。
- 反引號 `` `文字` `` 只會去掉反引號，文字照常顯示（不換字型）；常用來包住不該被排版檢查的英文或代碼。

## 圖片與圖說

```
![](../figures/screen-id.png)

圖 1.1. 圖名
```

- 圖片行：整行只有 `![](相對路徑)`，路徑相對於章節檔所在資料夾。方括號內的替代文字不會輸出。
- 圖片若存在於 `figuresDir`，連結應寫成從章節資料夾到該資料夾的相對路徑（預設 `../figures/檔名.png`）；`check_manual.py --fix` 會自動改正。
- 圖片之後的下一個非空白行必須是圖說：`圖 N.M. 圖名`。「圖」與數字間一個空格，`N.M` 後接英文句點，再一個空格接圖名。
- N 為章號；M 在章內從 1 起連續、不重複、依出現順序（check：number）。
- 圖名不超過 20 字，不列子圖，不寫「(a)」等標籤（check：caption、subfig）。
- 每張圖片在全書只能用一次（build 與 check 都會擋）；圖片不存在時 build 直接停止。
- 輸出：圖片置中，寬度為文字寬度（高度上限 21.5 cm，超過依比例縮小），帶 1 pt 淡灰色外框；圖說置中、10 pt 粗體，「圖 N.M.」為主色。圖片與圖說保持同頁。
- 不使用子圖：一張圖片一個圖號，不寫 `圖 1.2(a)`。舊式寫法 `【圖…】`、`圖 1-2` 也不允許（check：format）。

## 照片來源

圖中出現他人授權的照片時，在圖說正下方加一行：

```
圖 1.1. 圖名

> 照片來源：名稱，作者，授權，網址；名稱，作者，授權，網址
```

- 必須緊接在圖說之後（中間只能有空白行），否則 build 停止、check 報 credit。
- 每筆四欄以全形逗號「，」分隔；多筆以全形分號「；」分隔。網址只能是 ASCII 字元，以 http:// 或 https:// 開頭。
- 只標註圖中實際看得到的 CC BY 系列照片；CC0、公有領域不需標註。
- 輸出：4 pt 淡灰色置中，網址為可點選連結，與圖片、圖說同頁。

## 圖的引用

- 每個圖號都要在內文中被引用至少一次，引用的圖號必須存在（check：ref）。
- 寫法：`圖 1.1`（「圖」後的空格可省）、列舉 `圖 1.1、1.2`、範圍 `圖 1.1 至 1.3` 或 `圖 1.1 至圖 1.3`。
- 常見位置：句末括號 `(圖 1.1)`。
- 圖上標註框的標籤若是大寫字母（A、B），文中對應寫成小寫 `(a)`、`(b)`（同一個字母，大小寫視為相同）；`annotations` 檢查也照這個對應。**前言要預先說明這個讀法**（例如「圖上方框以大寫字母標示，內文以小寫括號 (a)、(b) 指稱」），否則讀者會以為文字與圖對不上。
- 標註標籤：圖上的框選標籤寫成半形 `(a)`、`(b)`，緊接在所指的畫面文字之後，例如「搜尋框」(a)。標籤要與 `圖 N.M` 在同一段落（設定 `annotations` 時會檢查）。
- 不可寫 `圖 1.1(a)` 或 `圖 1.1 (a)`（視為子圖，check：subfig）。
- 標題行、圖片行、圖說行、照片來源行中的圖號不算引用。

## 表格

```
| 欄位 | 說明 |
|---|---|
| 名稱 | 必填<br>最多 50 字 |
```

- 表頭列 + 分隔列（`|---|`，可寫 `:--:` 等對齊符號，但輸出不採用對齊）+ 至少一列內容。
- 每列欄數與表頭相同；儲存格內的 `|` 寫成 `\|`；表頭不可有空白儲存格；儲存格內不可放圖片（check：table）。內容列多於表頭時 build 停止。
- 儲存格內 `<br>` 為換行；反引號只去除，不換字型。
- 輸出：10 pt、0.5 pt 灰色框線、表頭粗體且跨頁重複、列不跨頁分割、欄寬依內容自動計算；表格後自動留一個空白段落。
- 以 `|` 開頭但後面沒有分隔列的行會被當成普通段落，check 會報錯。

## 注意框

```
> 注意：提醒內容。
```

- 以 `>` 開頭（照片來源行除外）的行為一般內文段落；若內容以「注意：」開頭，「注意：」三字為紅色粗體。
- 不是框線，只是引導詞上色；仍有首行縮排。

## 問答

```
問：問題內容。

答：回答內容。
```

- 行首為「問：」或「答：」（全形冒號）時，引導詞粗體（「問：」主色、「答：」灰綠），段落使用凸排，換行後文字對齊在標籤之後。
- 每個問、答各自一行。

## 本章重點與常見問題框

- 這兩個框都是**選用**的，沒有要求每章都要有；有就依下面寫法。
- `## 本章重點`、`## 常見問題` 兩個標題（文字必須完全相同、不帶編號）輸出為「── 本章重點 ────…」的字元框線標題。
- 其他不帶編號的 `##` 則照一般節標題外觀。

## 標點與排版規則

以下規則在內文、注意框、問答、表格行都會檢查；標題、圖片、圖說、照片來源行不檢查。「」引號內與反引號內的文字一律略過。

| 規則 | 錯誤 | 正確 | check 類別 |
|---|---|---|---|
| 括號用半形，外側與中文、英數字之間空一格 | `系統（後台）` | `系統 (後台)` | typo（`--fix` 自動修） |
| 中文與英文字母、數字之間空一格 | `共3筆`、`登入Email` | `共 3 筆`、`登入 Email` | spacing |
| 中文旁不用半形 `, ; : ! ?` | `完成,再按` | `完成，再按` | typo |
| 舊式圖號 | `【圖 1】`、`圖 1-2` | `圖 1.2` | format |

- 畫面上的按鈕、欄位、訊息用「」包住並照抄畫面文字，例如「申請媒合」。
- 英數字與中文之間的空格規則不適用於「」內，所以引用畫面文字時照原樣即可。

## 用語檢查

- 設定檔 `terms`：`{"錯誤用語": "正確用語"}`，該詞出現在可檢查的行中就報 term；值為 `null` 表示此詞完全禁用。
- 比對是單純的子字串比對，「」內也會比對。

## 選用檢查：圖表計畫、照片來源清單、標註標籤

設定檔對應的鍵為空時略過。路徑相對於設定檔所在資料夾。

- `figurePlan`：Markdown 表格，**恰好 8 欄**，欄位依序為：

  | 欄 | 名稱 | 內容 |
  |---|---|---|
  | 1 | 章 | 章號與章名，例如 `1 前台瀏覽`（同章後面各列可只寫章號） |
  | 2 | 圖號 | 例如 `圖 1.1` |
  | 3 | 圖名 | 圖說上「圖 N.M.」後面的名稱（腳本稱為子項） |
  | 4 | id | 圖片檔名（不含副檔名），也是 `figures/` 裡的檔名 |
  | 5 | 說明 | 這張圖是什麼畫面，給作者看，不印在手冊 |
  | 6 | 分類 | `放入` 或 `只拍不放`；只有這兩個值的列才會被解析 |
  | 7 | 故事時點 | 使用故事的時點或檢查點，沒有就填 `—` |
  | 8 | 標註 | 圖上標註框的標籤與意思，例如 `(a)搜尋框 (b)按鈕`，沒有就填 `—` |

  檢查圖號與計畫一致、「放入」的圖都有用到、「只拍不放」的圖沒被用、用到的圖都在計畫中。範本見 `templates/figure-plan.md`。
- `photoCredits`：Markdown 表格 `| File | URL | Author | License |`；名稱取檔名主檔名第一個「_」之前的部分。檢查每筆照片來源的作者、授權、網址與清單一致、只標註 CC BY、清單中每張 CC BY 照片都至少被標註一次。
- `annotations`：標註定義檔的 glob（例如 `../ui-inventory/states/*.boxes.json`），內容為 `{"圖片檔名": {"a": {"label": "..."}, ...}}`。檢查每個標籤 `(a)` 都在引用該圖的段落中出現。

## 常見錯誤對照

| 訊息類別 | 常見原因 |
|---|---|
| caption：圖說不在圖片正下方 | 圖片與圖說之間夾了其他文字，或連續兩張圖片共用一個圖說 |
| number：依順序應為 圖 N.K | 插入新圖後沒有重新編號 |
| ref：從未在敘述中被引用 | 內文只寫「如下圖」，沒寫圖號 |
| link：圖片檔不存在 | 相對路徑寫錯或檔名打錯 |
| table：此列有 X 格 | 儲存格內含未跳脫的 `|` |
| heading：標題層級與編號不符 | `###` 用了 `N.M`，或 `##` 用了 `N.M.K` |
