## 可調的排版偏好

下面這些數值都在專案的 `manual.style.json`，改檔再重建即可，不用動腳本。以下預設值是累積下來的使用偏好：

| 鍵 | 預設 | 意義 |
|---|---|---|
| `bodySize`、`h1Size`、`h2Size`、`h3Size` | 11、18、14、12 | 內文與各層標題字級（pt） |
| `captionSize`、`tableSize` | 10、10 | 圖說與表格字級 |
| `citeSize`、`citeColor` | 4、A6A6A6 | 照片來源字級與顏色 |
| `firstLineIndentChars` | 2 | 內文首行縮排字元數，0 為不縮排 |
| `align` | both | 內文對齊：both 左右對齊、left、center、right |
| `lineSpacing` | 1.0 | 行距倍數 |
| `paragraphSpacingPt` | 0 | 前後段距（pt） |
| `pictureOutlineColor`、`pictureOutlinePt` | A6A6A6、1 | 圖片外框顏色與粗細 |
| `marginCm`、`maxImageHeightCm` | 2.2、21.5 | 頁邊界與圖高上限 |
| `tableCellMarginTwips` | [0, 0, 0, 0] | 表格儲存格內距，依序上、左、下、右（twips，20 = 1 pt） |
| `ruleChars`、`boxRuleChars` | 73、46 | 章標題下方「─」線與框標題尾端「─」的字數（要等於文字寬度） |
| `tableAutofit` | false | false 為固定欄寬，大小不隨文字變動；true 讓 Word 依內容自動調整 |

下面各節描述的是**預設樣子**；字型在 `manual.config.json` 的 `bodyFontEastAsia` / `bodyFontLatin`，章名顏色是 `accentColor`。
不在表裡的（純文字外觀的結構、圖說格式、固定目錄、標點溢出與貼齊格線的關閉）是工具內建的設計，要改就得修改 `scripts/build_manual.py`，改之前先讀 [defaults.md](defaults.md)。

## 設計想法

文件要「看起來像純文字檔」：所有段落都是 Normal 樣式，沒有標題樣式、大綱階層、框線、底色，也沒有 Word 的章節收合功能。
版面只靠 run 層級的字型、字級、粗體、顏色，以及文字符號（「▍」、「── 本章重點 ──」、「─」線）。
使用者曾經兩次糾正「怎麼不是純文字」，所以不要為了方便而套用任何 Word 結構性功能（標題樣式、自動目錄、段落框線）。

## 全域設定

只設定一次，放在 docDefaults 與 Normal 樣式，段落與文字自動繼承：

- 字型：東亞文字微軟正黑體，英文與數字 Arial。**不在個別 run 上設字型。**
- 前後段距 0、行距單行、取消「貼齊文件格線」、取消「允許標點符號溢出邊界」。
- 內文左右對齊（兩端對齊；最後一行與單行不會被拉開）。
- 首行縮排 2 字元。所有內文段落（一般敘述、注意事項）都繼承它。
- 頁面 A4，邊界 2.2 cm，內文 11 pt。

## 各類段落

必須取消首行縮排的段落（明確覆寫縮排為 0）：圖片段落、圖說、章與節標題、字元線、封面各行、目錄各行、空白與分頁段落、頁尾頁碼段落。
這些置中或靠齊的段落若帶縮排，會偏離中心。

| 段落 | 格式 |
|---|---|
| 章標題 | 18 pt 粗體，章名色（設定檔 `accentColor`）；前面一個空白段落隔開，不換頁 |
| 節標題 | 14 pt 粗體，前綴「▍」 |
| 小節標題（`###`） | 12 pt 粗體，無縮排 |
| 內文 | 11 pt，繼承 Normal |
| 注意事項 | 以「注意：」開頭，開頭文字粗體上色，其餘同內文 |
| 問與答 | 「問：」「答：」開頭，**凸排**：左縮 2 字元、凸出 2 字元，換行後對齊標籤後的文字；無首行縮排 |
| 框標題 | 「── 本章重點 ──」「── 常見問題 ──」，12 pt，字元線補滿文字寬度 |
| 字元線 | 灰色「─」，9 pt，數量等於文字寬度 |

章節**不換頁**：章標題直接接在前一章後面。只有兩處分頁：封面到目錄、目錄到正文。

## 圖與圖說

- 圖片段落與圖說段落都置中；圖片段落設「與下段同頁」，圖說不會單獨落在下一頁最上面。
- 每張圖有 1 pt 灰色（#A6A6A6）外框，畫在圖片本身（drawing 層級），不是段落框線。**不要黑色。**
  圖片會縮小 1 pt，讓外框不超出文字寬度。圖高上限 21.5 cm。
- 圖說「圖 N.M. 名稱」在圖片正下方，10 pt。
- 照片來源行（`> 照片來源：…`）緊接在圖說後：置中、4 pt、淡灰（#A6A6A6）、無縮排、不跨頁；網址是可點選的連結，直接格式（大小、灰色、底線），不套超連結樣式。
  圖片、圖說、照片來源三者保持同頁。

## 目錄與頁碼

- **固定文字目錄**，不用 Word 自動目錄（它會自動套用「目錄 1」「目錄 2」樣式，破壞純文字外觀）。
- 每行是「標題＜Tab＞頁碼」，只有一個靠右的定位點，點狀前導線，位置在右文字邊界。
- 頁碼分兩階段取得：第一階段先用占位數字建置，用 Word 實測每章起始頁；第二階段把實測頁碼寫回目錄再建置。
- 頁尾頁碼段落置中。

## 表格

簡單表格（GitHub 風格的 markdown 表格）轉成 Word 表格，只用直接格式：

- 不套表格樣式；細單線框（0.5 pt、#808080），全部邊線與內線；寬度等於文字寬度；欄寬在建置時依內容計算後固定（`tableAutofit` 為 false，Word 不會再隨文字調整）；不上底色。
- 儲存格內距預設全為 0（`tableCellMarginTwips`），要留白就調大。
- 首列粗體，跨頁時重複出現，且與下一列同頁；每列不跨頁。
- 儲存格內是 Normal 文字，縮排覆寫為 0，字級 10 pt。
- 表格後面留一個空白段落。

## 文件屬性

作者與最後修改者填設定檔的 `author`（PDF 也帶這個作者）。不要留成 python-docx 預設的「python-docx」。

## 字級與尺寸

章標題 18、節標題 14、小節標題 12、內文 11、圖說 10、表格 10、照片來源 4（pt）。
照片來源字級只在需要更小更淡時才調整，改字級要同步檢查頁面是否仍然填滿。
